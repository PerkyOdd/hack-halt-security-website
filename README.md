# Hack Halt Security website

Next.js website inspired by the current Hack Halt Security preview: dark navy/blue palette, centered scroll-reactive 3D-style background typography, Daksha concept carousel, About section, and side navigation.

## Run locally
Requires Node.js 20+.
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Publish
1. Create a GitHub repository and upload these files.
2. In Vercel, choose **Add New → Project**, import your GitHub repository, and deploy with the default Next.js settings.

## Logo
The current Floot project uses a private project asset path for the exact original logo. To add it to this standalone repo, place the original logo file at `public/hack-halt-security-logo.png` and replace the text brand lockup in `app/page.tsx`. Preserve the logo exactly as supplied.

Daksha is described as in development/concept preview, not as a live school service.
